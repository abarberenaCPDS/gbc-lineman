# Hero concept variants

Created with built-in image generation using ../experience-characters.png as reference. Concepts only; not engine-ready sprites.

Shared prompt: Preserve the cream hard hat, orange workwear, dark pants and boots; show idle, walking, repairing, and cable-carrying poses on slate gray with crisp pixel-art styling.

- Classic lineman: slender familiar silhouette, refined helmet and gloved hands.
- Storm worker: broader rain jacket, reflective stripe, tool belt and heavy boots.
- Neighborhood hero: approachable face, larger helmet, rolled sleeves and relaxed confidence.
